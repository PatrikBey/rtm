KEY ALGORITHMIC FEATURES
========================

Graph Construction (Script 1):
  • Layer aggregation: Patient-specific information consolidated
  • BEHAVIOUR layer: Behavioral scores weighted onto network edges
  • Co-occurrence layer: Lesion co-occurrence patterns preserved
  • Edge filtering: Optional pruning of sparse connections
  • Result: Undirected, weighted, multi-layer graph

SBM Fitting (Script 2):
  • Model: BlockStateNested (hierarchical, non-parametric Bayesian)
  • Optimization: Simulated annealing (1-10 temperature range)
  • MCMC: 100k posterior samples with 50k burn-in
  • Edge distributions: BEHAVIOUR=Gaussian, Co-occurrence=Poisson
  • Result: Community structure + entropy quality metric

Null Validation (Script 3):
  • Procedure: Behavioral score permutation (fully randomized)
  • Iterations: 100 null models (configurable)
  • Each null: Rebuild graph → fit SBM → extract entropy
  • Distribution: Empirical null entropy from 100 models
  • Comparison: Z-score, percentile rank, p-value


INTERPRETATION FRAMEWORK
========================

Entropy Values:
  • Real entropy << null mean:  ✓ Significant structure (p < 0.05)
  • Real entropy ≈ null mean:   ✗ No significant structure (p ≥ 0.05)
  • Real entropy >> null mean:  ✗ Worse fit than random (unusual)

Community Interpretation:
  • Blocks represent functionally-related regions
  • Within-block edges: high behavioral/co-occurrence coupling
  • Between-block edges: weak coupling
  • Node assignment: regions contributing to fluid intelligence

Statistical Interpretation:
  • p < 0.05: Community structure unlikely by chance
  • Percentile < 5: Real entropy in lower tail of distribution
  • Z < -2: Very significant (rare under null)
